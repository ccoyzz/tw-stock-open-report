# 新版「台股每日開盤統整」排程任務提示詞

**使用方式**：把下方分隔線以下的全部文字，貼到 Claude 排程任務的提示詞欄位，取代舊的內容。

**排程時間**：台灣時間交易日 09:40。如果排程是依你裝置的時區設定，人在雪梨時要換算：

| 期間 | 雪梨時間 |
|---|---|
| 10 月第一個週日 ～ 4 月第一個週日（夏令時間） | 12:40 |
| 4 月第一個週日 ～ 10 月第一個週日 | 11:40 |

與舊版的差異只有三處：新增「第零步」讀取資料檔；第二段（直播）與第三段（開盤數據）改為優先使用資料檔。其餘內容不變。

---

請以繁體中文製作「台股每日開盤統整」報告。執行時間約為台灣時間（Asia/Taipei）交易日 09:40。報告中所有「今天」「前一交易日」都以台灣時間為準，不要用執行環境或使用者所在地的時區。

讀取網頁一律用 WebFetch 工具（若沒有，就用 web-fetch 代理）。任何網址若回報被擋（robots、security block 等），不要改用 curl、python 等其他方式抓取，改用下方列出的備援來源並註明。

第零步：讀取自動抓取程式產生的資料檔
- 網址：https://raw.githubusercontent.com/ccoyzz/tw-stock-open-report/data/YYYY-MM-DD.json ，把 YYYY-MM-DD 換成今天的台灣日期（例如 2026-11-18 就讀 .../data/2026-11-18.json）。
- 一定要讀當天日期的檔名，不要讀 latest.json：網頁讀取工具會快取同一個網址，latest.json 可能讀到前幾天的舊內容。
- 讀不到（例如 404）代表今天的資料尚未產生，視為「資料檔不可用」。
- 這個檔案由一支每天早上自動執行的程式產生，內容是當天的開盤數據（quotes）與游庭皓直播重點（live）。請原樣讀取 JSON 的欄位值，不要改寫數字。
- 先檢查三件事：(1) 讀取成功；(2) `trade_date` 等於今天的台灣日期；(3) `market_status` 不是 `error`。三項都成立才算「資料檔可用」，否則視為「資料檔不可用」，後面的段落改用各段寫明的備援做法，並在報告中註明「自動資料檔今日不可用」。
- 若 `error` 欄位有內容，在報告的資料來源區註明。

第一步：確認今天台股是否開市
- 若資料檔可用且 `market_status` 為 `closed`，或資料檔不可用，請用網路搜尋確認今天台股是否開市。
- 若資料檔可用且 `market_status` 為 `open`，代表證交所今天已有開盤資料，可直接視為開市。
- 遇國定假日、颱風假等休市時，只回報「今日台股休市」及原因，然後結束，不要做其他任何步驟。

確認開市後，報告內容請包含以下段落：

一、盤前消息統整
- 美股前一交易日收盤結果：道瓊、S&P 500、那斯達克、費城半導體指數的收盤點數與漲跌幅，以及台積電 ADR 的漲跌。（中央社「美股收盤」新聞、鏡週刊、自由財經通常都有完整數字。）
- 影響台股的重要國際與國內消息（Fed／利率、美國經濟數據、科技大廠財報、地緣政治、匯率等），挑最重要的 3–5 則，每則 1–2 句。經濟日報每天清晨的「五件財經大事搶先看」可作為參考。
- 補充指標：
  - 台指期夜盤：讀取期交所盤後行情表 https://www.taifex.com.tw/cht/3/futDailyMarketReport ，取「台指期（TX）」近月合約的夜盤（盤後交易時段）最後成交價與漲跌，並確認表頭的交易時段是前一交易日 15:00 到今日 05:00。
  - 新台幣兌美元前一交易日收盤匯率與升貶。
  - 前一交易日三大法人（外資、投信、自營商）買賣超金額。
- 建議消息來源：美股用 Reuters、CNBC、中央社；台股用鉅亨網、經濟日報、工商時報、自由財經；官方數據用證交所 OpenAPI 與期交所。

二、游庭皓的財經皓角：當日直播重點
依資料檔的 `live.status` 處理：
- `ok`：`live.summary` 是自動程式請 AI 看完當天直播後整理的重點。請根據它，用自己的話分析並總結他當天的主要觀點，包括他對美股、台股、總經、產業或個股的看法，以及他提到的風險或觀察重點。不要大段照抄摘要。
  - 這份摘要是 AI 自動產生的，數字可能有誤。摘要中的數字若與本報告其他來源矛盾，以其他來源為準，並註明「直播摘要此處數字與其他來源不符」。
  - 說明他的觀點和本報告其他消息來源一致或不同的地方。
  - 附上影片連結（`live.url`）與標題（`live.title`）。
- `title_only`：寫「僅取得標題」，附上 `live.title` 與 `live.url`，不要憑標題推測或編造內容。
- `pending`、`not_found`，或資料檔不可用：寫「今日未取得直播內容」，不要推測他今天的觀點。
- 不需要自行搜尋 YouTube、Apple Podcasts 或其他來源。

三、開盤數據（必須附前一交易日收盤 vs 今日開盤的數字對比）
請用表格呈現：名稱｜代號｜前日收盤｜今日開盤｜漲跌點數／金額｜漲跌幅%
- 台灣加權指數（TAIEX）
- 元大台灣50（0050）
- 元大台灣50正2（00631L）
- 群益臺灣加權正2（00685L）

資料檔可用時：
1. 表格數字直接取資料檔 `quotes` 中各標的的 `prev_close`、`open`、`change`、`change_pct`，照原樣填入，不要重新計算。
2. `status` 為 `missing` 的標的：資料檔有值的欄位照填，沒有值的欄位寫「今日開盤未取得」，並在表格下方寫出 `reason`。不要自行猜測或用其他網站的數字補上，除非依下方「資料檔不可用時」的步驟查到且通過核對。
3. `prev_close_mismatch` 為 true 的標的：在表格下方註明即時報價的昨收（`prev_close`）與證交所官方收盤（`official_prev_close`）不一致，並列出兩個數字。
4. 用中央社「台股開盤」新聞（約 09:00–09:05 發布）核對加權指數的開盤點數與漲跌點數；不一致時兩者都列出並註明。
5. 來源註明：「證交所即時報價（由自動抓取程式於開盤後取得）」，並附資料檔的 `generated_at` 時間。

資料檔不可用時（備援，與舊版做法相同）：
1. 前日收盤（ETF）：讀取證交所 OpenAPI https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL ，找出 Code 為 0050、00631L、00685L 的 ClosingPrice。Date 欄是民國年格式（例如 1151110 = 2026-11-10），請確認它是前一交易日。這是官方收盤價，以它為準。
2. 今日開盤（ETF）：讀取鉅亨網個股頁 https://www.cnyes.com/twstock/0050 、https://www.cnyes.com/twstock/00631L 、https://www.cnyes.com/twstock/00685L 的「今開」。頁面時間戳可能是 UTC，請用「昨收」是否等於步驟 1 的官方收盤價來確認資料是今天的；不相符就代表頁面仍是舊資料，標註「今日開盤未取得」，不要填數字。
3. 加權指數：用中央社「台股開盤」新聞取得開盤點數與漲跌點數，前日收盤＝開盤−漲跌點數，再用其他新聞（鉅亨網、經濟日報、自由財經）報導的前一日收盤點數核對。證交所 OpenAPI 的 MI_INDEX 常落後一天，只有日期相符時才可用來核對。
4. 不要使用證交所 MIS（mis.twse.com.tw）與證交所網站 www.twse.com.tw 的 rwd 頁面，它們會被擋。Yahoo 股市報價頁常停在舊資料，不要使用。
5. 漲跌＝開盤−前日收盤，漲跌幅＝(開盤−前日收盤)/前日收盤×100%，請用 Bash 執行 python 計算，不要心算。

不論哪一種情況，都在表格下方註明每個數字的來源。任何查不到或來源不一致的數字都要明確註記，不要猜測數字。

四、漲跌原因推測
根據開盤走勢、上述新聞消息與游庭皓直播的觀點，用 3–5 點說明你推測的漲跌原因（例如美股科技股帶動、台積電 ADR 表現、外資動向、匯率、特定產業消息），並標示這是推測而非確定結論。

五、今日觀察重點
列出 2–3 個今天盤中值得留意的事項（例如重要經濟數據公布時間、法說會、除權息）。

注意事項：
- 只做資訊整理與分析，不提供個人化投資建議或買賣建議；報告結尾加一句「以上為資訊整理，非投資建議」。
- 報告最後附上「資料來源」清單（含連結），其中包含今天讀取的自動資料檔網址。
- 用 SendUserMessage 將完整報告送給使用者。
